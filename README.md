# 笔仙 Bixian

本地优先的 Rust 桌面 AI 长篇小说创作工具。人写为主、AI 辅助；人物图谱、伏笔追踪、灵感碰撞。

## M3 功能

- **阅读模式**：Ribbon 切「阅读」进入全书沉浸阅读——TipTap 只读渲染，字号/行距/字距/段距/页宽/页边/字体/两端对齐逐项可调；四套底色预设 + 自定义背景图（双层渐变遮罩保证文字可读）；进度记忆（每本书记住读到哪章哪个位置）；Ctrl+←/→ 换章、Esc 返回写作。
- **阅读四边面板**：鼠标移到屏幕四边停住唤出（500ms 防误触）——左目录（过滤/当前章高亮）、上信息（本次阅读时长/进度/全屏）、下进度条（滑条跳章）、右设置（分区带搜索定位，输入关键词直接滚到对应设置项）；面板可锁定常驻，F6-F9 快捷开合。
- **纸张纹理**：设置 → 外观 → 纸张纹理，六种内置 SVG 纹理（纸张噪声/圆点/网格/横线/织物）铺满整页，强度/缩放/混合模式可调。
- **编辑器排版**：段首缩进两字、行高/段距/字距三滑条（设置 → 外观 → 正文排版）；分场线渲染为居中 ❖ 符号。
- **右侧 dock 收缩**：Ctrl+\ 折叠/展开右侧面板列，拖宽记忆；写作区侧栏（Ctrl+B）与 dock 均可收纳，全屏留给正文。
- **悬浮大纲**：Alt+O 呼出可拖拽浮窗——上半本章两级小标题（# 或中文章题自动抽取，点击跳转正文），下半全书章节列表；位置记忆。
- **统计增强**：右栏「统计」面板——今日/本周/30 天/累计/日均/中位/速度十项指标卡、30 天柱状趋势（叠加日目标线）、6 个月写作热力图、连续天数 🔥、日目标环形进度；每本书目标字数 + 进度条 + 按近期日均预估完本日期。
- **伏笔面板**：右栏「伏笔」——登记伏笔（埋设章/计划回收章/备注），紧急度四态（超期红/紧急橙/活跃蓝/已回收绿，剩余 ≤5 章或拖过两倍计划跨度即转紧急），章轴甘特简版一屏看全书伏笔分布。
- **碰碰车批量加词**：粘贴整段文字自动分词（空格/标点/分隔符切分）、去重预览、一键入库。

## M2 功能

- **导航重构**：左侧 48px Ribbon 竖条切换一级视图（写作 / 碰碰车 / 阅读）；侧栏可折叠（Ctrl+B），拖宽记忆。
- **多主题**：设置 → 外观，六套主题（笔仙深/浅、墨色、羊皮纸、护眼绿、午夜蓝）+ 明暗跟随系统 + UI 缩放。
- **ACP agent 直连**：设置 → Agent 探测并启用本机 agent（Claude Code / Codex / Gemini 等），免手填 API Key；AI 面板顶栏切换「Agent / API 直连」后端；agent 请求工具授权时弹出权限卡。API 直连保留为高级后备。
- **回收站**：删除章/书都是软删除（章 md 移入 `<书>/.trash/`、书目录移入 `.trash_books/`），侧栏「书籍」行右侧回收站入口可恢复或彻底删除。
- **版本历史**：编辑区顶栏「历史」，与当前正文按行 diff、一键恢复。自动保存每 5 分钟记一版（单次改动超 200 字立即记），上限 50 版；恢复前会自动把当前内容存一版，恢复本身可再恢复。
- **导入导出**：导入 txt/docx（自动识别 GBK 等编码；按「卷 / 第 N 章 / 序章·楔子·番外」分章；先预览再勾选）；导出 txt（段首缩进、CRLF）或 docx。
- **全书搜索**：Ctrl+Shift+F，跨章命中按章分组、高亮，点击跳章并定位到该行。
- **碰碰车**：词库 chips 增删、随机碰撞 2-4 个词、满意的组合存成灵感卡。
- **写作统计**：侧栏底部「今日 N 字」，只计手写增量（粘贴与 AI 采纳不计，切章不误计）。
- **敏感词检查**：编辑区顶栏「检查」，命中列表 + 词库管理（一行一词，可从 txt 导入）；只报告，不改正文。

## M1 功能

- **服务商配置**：设置 → AI 服务商，填 API 地址 / Key / 模型 / 最大 Token / 温度；「设为使用中」切换当前服务商。
- **流式续写**：AI 续写面板输入写作指令，Enter 发送、Shift+Enter 换行；流式渲染可随时「停止」，满意后「采纳进正文」。
- **文风库**：维护文风卡（提示词 + 范例 + 标签），按书指定激活文风，续写时自动注入。
- **上下文预览**：面板顶栏「预览」摊开本次续写的全部注入槽位（默认提示 / 文风 / 上一章结尾 / 当前章正文 / 写作指令），逐槽显示字数与估算 token——所有注入可见，无黑盒。

## 配置 API

1. 准备一个 OpenAI 兼容的 `/chat/completions` 服务（DeepSeek、OpenAI、本地 Ollama 等均可）。
2. 打开「设置 → AI 服务商 → 新增服务商」，填写：
   - **API 地址**：到 `/v1` 为止，如 `https://api.deepseek.com/v1`（须以 http 开头）
   - **API Key**、**模型**：如 `deepseek-chat`
   - **最大 Token / 温度**：可选，默认 4096 / 0.7
3. 保存后点「设为使用中」，该服务商即用于 AI 续写。

## 开发

    pnpm install
    pnpm tauri dev      # 开发运行（首次编译 Rust 约 2-5 分钟）
    pnpm test           # 前端测试
    cd src-tauri && cargo test   # Rust 测试
    pnpm tauri build    # 打包

## 数据位置

- 正文 markdown：`%APPDATA%/com.bixian.app/library/<书>/manuscript/*.md`（唯一真源，可随时用侧栏「重建索引」恢复数据库）。
- 库内隐藏目录（均不参与扫描/搜索/导出）：`<书>/.trash/`（章节回收站）、`<书>/.history/`（版本快照）、`.trash_books/`（书籍回收站）。
- 数据库（书 / 章节索引 / 服务商 / 文风卡 / 会话与消息 / 词库 / 灵感卡 / 写作统计 / 伏笔 / 通用设置）：`%APPDATA%/com.bixian.app/bixian.db`；阅读背景图：`%APPDATA%/com.bixian.app/background/`。

设计文档：`docs/specs/2026-09-19-bixian-spec.md`；当前里程碑计划：`docs/superpowers/plans/`。
